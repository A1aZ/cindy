# 用量历史图表与日期选择

适用入口：设置 → 用量历史（`UsageHistorySection`）。依据为 2026-09-07 所有者圆角裁决与 `DESIGN.md §5`；规范登记由 [PR #4072](https://github.com/makecindy/cindy/pull/4072) 引入，本次实现需在其合入后交付。

## 可见层与布局

| 可见角色 | 半径依据 | 尺寸与数据映射 |
| --- | --- | --- |
| 热力图日格 | §5 成员 `usage-heatmap-day` | 可见格 12×12px，行列间隔 3px。金额/Token 口径、分位色阶、日期窗口算法沿用组件原逻辑；静止形状和网格密度不随点击启用与否改变；09-08 登记的交互强调见下。滚动视口内预留 3px 外围空间，容纳边缘指示器。 |
| 每日 Token 柱 | §5 成员 `usage-token-bar` | 固定近 30 天、柱间隔 3px，均分可用绘图区宽度；不设每柱 24px 最小宽度或 807px 容器下限。非零高度按原比例计算、最低 3px；零值日保留 2px 高。堆叠顺序、tooltip 与纵轴刻度不变；分类颜色按下述 09-08 裁决更新。 |

柱体自身的裁剪采用同一登记处理。按钮的透明命中层不裁剪数据图元，不继承 pill 外形；键盘按钮语义、可访问日期/用量名称和 `aria-pressed` 保留。非交互渲染分支仍不创建按钮，其格子遵守同一成员登记。

## 配色（2026-09-08 所有者裁决）

热力图用蓝色深浅表示用量，沿用四档强度映射，零值日保留 `--surface-chip`。高值色使用 `--usage-heatmap-high`。柱图前五个模型依次使用 `--usage-model-1` … `--usage-model-5`（蓝、青、紫、绿、琥珀），未列入 colorOrder 的模型统一中性灰；即便不足五个模型，“其它”也不占用某一模型的颜色。值在 colors.ts 注册为已有进程类别调色板的别名，原进程 Token/状态语义及用户主题均不修改。

颜色对应完整图表窗口的模型顺序，与明细表同一模型的色块、占比短条保持一致，不因日期筛选后的排序变化而跳色。Agent 与任务排行仍用既有中性色；本裁决不登记新形状、不扩张其几何用途。颜色表示类别，不表示“成功/警告”。Tooltip 和带名称的明细表仍提供非颜色识别渠道；分类颜色不能保证仅靠颜色满足所有色觉条件。

## 点击、焦点与选中（2026-09-08 更新）

- 用户明确选择“悬停微弹，选中保持”。**本段替代 09-07 对这两个成员一概不缩放的限制**，仅登记下列状态几何；基础圆角、数据映射及命中规则保留。
- 热力图从 12×12px 平滑扩大到 14×14px，中心不动；柱体只增加 2px 宽度，高度、基线及各模型分段高度不变。进入曲线只有一次轻微超调，扩张总量小于 3px 间隙。直接调整可见层的宽/高而非整体 scale，确保**四角在动画中仍为 2px**。
- 进入/聚焦/选中使用 `--motion-base`（200ms）与组件专属 `--usage-mark-ease: cubic-bezier(0.2, 0.8, 0.25, 1.18)`；退出使用 `--motion-fast`（150ms）与 `--motion-ease-out`。同一已选中图元再次悬停不重复弹跳；选中后移开指针仍保持放大。禁止循环动画，不移动其他图元。
- 命中框始终保持原尺寸：热力图 12×12px，柱图高度 `max(24px, 柱高)`、宽度按可用空间均分。放大的可见层和指示层均 `pointer-events: none`，不把相邻日期的命中区叠在一起。
- Hover 不改填充色、强度档位或堆叠比例。选中保留独立的 1px 中性细轮廓（偏移 2px），键盘焦点用 2px `--focus-ring` 轮廓（偏移 1px）；这些指示不覆盖数据填充。无额外阴影或亮度变化。
- `prefers-reduced-motion: reduce` 时不播放过渡，立即落到对应大小与清晰的焦点/选中状态；触摸设备不依赖 hover，禁用柱不触发强调。
- 原生 Enter/Space 点击继续使用原 `handleDayClick` → `day:YYYY-MM-DD` 筛选路径。图表继续显示固定窗口，概览和明细按所选日期过滤；单日模式下任务明细的既有隐藏规则不变。

## 等价单日选择

`UsageDateFilter` 与密度恢复同次交付，常驻同一页面、位于图表之前：原生日期输入复用标准 `Input`（36px 高、190px 宽），提交动作复用标准 `Button`（36px 高）。输入可编辑年月日，支持系统日期选择器与键盘提交；不设最早日期限制，因此覆盖热力图补齐的空白日期和全部历史可选日。最大日期取 main 返回的 `todayKey`。

编辑草稿日期不会立即改变筛选；“查看当天”或 Enter 提交有效日期后调用同一个 `handleDayClick`。空值、无效日期和未来日期不提交。点图表会同步日期输入，切回相对范围会清空日期选择。原有所有时间、最近 30 天、最近 7 天、今天预设保留。

这是 §5 的 Equivalent 路径的具体消费者，不能推广为所有 data mark 的尺寸豁免，也不能先保留密集目标、后移除等价入口。Light/Dark 颜色均走已有语义 Token；系统日期控件的 `color-scheme` 随模式切换。
