# 用量历史图表与日期选择

适用入口：设置 → 用量历史（`UsageHistorySection`）。依据为 2026-09-07 所有者圆角裁决与 `DESIGN.md §5`；规范登记由 [PR #4072](https://github.com/makecindy/cindy/pull/4072) 引入，本次实现需在其合入后交付。

## 可见层与布局

| 可见角色 | 半径依据 | 尺寸与数据映射 |
| --- | --- | --- |
| 热力图日格 | §5 成员 `usage-heatmap-day` | 可见格 12×12px，行列间隔 3px。金额/Token 口径、分位色阶、日期窗口算法沿用组件原逻辑；点击启用与否不改变形状或网格密度。滚动视口内预留 3px 外围空间，容纳边缘指示器。 |
| 每日 Token 柱 | §5 成员 `usage-token-bar` | 固定近 30 天、柱间隔 3px，均分可用绘图区宽度；不设每柱 24px 最小宽度或 807px 容器下限。非零高度按原比例计算、最低 3px；零值日保留 2px 高。堆叠顺序、分类颜色、tooltip 与纵轴刻度不变。 |

柱体自身的裁剪采用同一登记处理。按钮的透明命中层不裁剪数据图元，不继承 pill 外形；键盘按钮语义、可访问日期/用量名称和 `aria-pressed` 保留。非交互渲染分支仍不创建按钮，其格子遵守同一成员登记。

## 点击、焦点与选中

- 热力图命中区域与日格同尺寸，不相互重叠；柱图点击高度仍为 `max(24px, 可见柱高)`，宽度随列自适应。
- 每个交互图元有独立、不可命中的指示层。指示器沿相应命中框绘制，角处理随关联登记成员；热力图为日格框，柱图为该列的命中框。
- hover 使用 `--text-tertiary` 的 1px 外轮廓；键盘焦点和选中使用 `--focus-ring` 的 2px 外轮廓，偏移 1px。指示层不填充、不缩放、不改动数据色阶或堆叠颜色。禁用柱不显示 hover 指示。
- 原生 Enter/Space 点击继续使用原 `handleDayClick` → `day:YYYY-MM-DD` 筛选路径。图表继续显示固定窗口，概览和明细按所选日期过滤；单日模式下任务明细的既有隐藏规则不变。

## 等价单日选择

`UsageDateFilter` 与密度恢复同次交付，常驻同一页面、位于图表之前：原生日期输入复用标准 `Input`（36px 高、190px 宽），提交动作复用标准 `Button`（36px 高）。输入可编辑年月日，支持系统日期选择器与键盘提交；不设最早日期限制，因此覆盖热力图补齐的空白日期和全部历史可选日。最大日期取 main 返回的 `todayKey`。

编辑草稿日期不会立即改变筛选；“查看当天”或 Enter 提交有效日期后调用同一个 `handleDayClick`。空值、无效日期和未来日期不提交。点图表会同步日期输入，切回相对范围会清空日期选择。原有所有时间、最近 30 天、最近 7 天、今天预设保留。

这是 §5 的 Equivalent 路径的具体消费者，不能推广为所有 data mark 的尺寸豁免，也不能先保留密集目标、后移除等价入口。Light/Dark 颜色均走已有语义 Token；系统日期控件的 `color-scheme` 随模式切换。
